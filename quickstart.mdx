<Steps>
  <Step title="Get an API key">
    Sign up and copy your key from the [dashboard](https://prefetch.io/dashboard). The Free plan includes 1,000 credits a month. Set the key in your shell:

    ```bash
    export PREFETCH_API_KEY="your_api_key_here"
    ```

    Keep it on your server. Don't commit it or put it in browser code.
  </Step>

  <Step title="Make a request">
    `/classify` tells you what kind of business a website is. It costs 5 credits.

    ```bash
    curl "https://api.prefetch.io/classify?url=https://stripe.com" \
      -H "X-API-Key: $PREFETCH_API_KEY"
    ```
  </Step>

  <Step title="Check the response">
    Every response has the same envelope: `success`, then `data`, then `meta`.

    ```json
    {
      "success": true,
      "data": {
        "domain": "stripe.com",
        "url": "https://stripe.com/",
        "classification": {
          "iab_id": "IAB3-4",
          "iab_parent_id": "IAB3",
          "category": "Business",
          "subcategory": "Business Software",
          "tagline_description": "A developer-first payments and financial infrastructure platform for online and in-person commerce.",
          "description": "A payments and financial-technology platform that lets businesses accept and process online and in-person payments…",
          "stock_tickers": [],
          "isins": []
        }
      },
      "meta": {
        "requestId": "a3f2c1d4-7b6e-4f2a-9c1d-8e3f2a1b4c5d",
        "durationMs": 196
      }
    }
    ```
  </Step>

  <Step title="Try more">
    `/enrich` returns brand, company and industry in one call, for 12 credits:

    ```bash
    curl "https://api.prefetch.io/enrich?url=https://stripe.com" \
      -H "X-API-Key: $PREFETCH_API_KEY"
    ```
  </Step>
</Steps>

## From your code

There's no SDK to install. Any HTTP client works:

<CodeGroup>

```javascript Node.js
const res = await fetch("https://api.prefetch.io/classify?url=https://stripe.com", {
  headers: { "X-API-Key": process.env.PREFETCH_API_KEY },
});
const body = await res.json();

if (!body.success) {
  throw new Error(`${body.error_code}: ${body.error}`);
}

console.log(body.data.classification.category); // "Business"
```

```python Python
import os
import requests

r = requests.get(
    "https://api.prefetch.io/classify",
    params={"url": "https://stripe.com"},
    headers={"X-API-Key": os.environ["PREFETCH_API_KEY"]},
)
body = r.json()

if not body["success"]:
    raise Exception(f"{body['error_code']}: {body['error']}")

print(body["data"]["classification"]["category"])  # "Business"
```

```typescript TypeScript
type ClassifyResponse =
  | {
      success: true;
      data: {
        url: string;
        domain: string;
        classification: { category: string; subcategory: string | null; description: string };
      };
    }
  | { success: false; error: string; error_code: string; retryable: boolean };

const url = `https://api.prefetch.io/classify?url=${encodeURIComponent("https://stripe.com")}`;
const res = await fetch(url, { headers: { "X-API-Key": process.env.PREFETCH_API_KEY! } });
const body = (await res.json()) as ClassifyResponse;

if (!body.success) throw new Error(`${body.error_code}: ${body.error}`);
console.log(body.data.classification.category); // "Business"
```

</CodeGroup>

## If the request fails

Errors use the same envelope, with `success: false`:

<ErrorEnvelope />

| Status | What to do |
|---|---|
| `401` | No key reached the API. Check the `X-API-Key` header and that the environment variable is set. |
| `403` | The key is wrong, revoked or out of credits. Check `error_code`. |
| `422` | The site couldn't be read, for example `DNS_RESOLUTION_FAILED`. Check the URL. |
| `429` | Too many requests at once. Wait a moment and retry. See [Rate limits](/concepts/rate-limits). |

Failed requests are never charged. See [Error handling](/concepts/errors) for every code.
