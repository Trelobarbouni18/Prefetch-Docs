Prefetch turns any website into data you can use:

- **The company behind it:** brand colors and logos, legal name, contacts, industry and design system.
- **The pages on it:** clean markdown, structured JSON, screenshots, every URL, or the whole site.
- **What changes on it:** monitors that tell you, by webhook or email, when a page changes in a way you care about.

One API key covers all of it, over REST or [MCP](/mcp/overview). Failed requests are never charged, and the [Free plan](/concepts/credits#plans) includes 1,000 credits a month.

```bash
curl "https://api.prefetch.io/enrich?url=stripe.com" \
  -H "X-API-Key: $PREFETCH_API_KEY"
```

```json
{
  "success": true,
  "data": {
    "domain": "stripe.com",
    "brand": { "colors": { "brand_colors": [{ "hex": "#635BFF", "name": "Medium Slate Blue" }] }, "logos": { "primary": { "url": "https://curated.prefetch.io/…/primary.svg" } } },
    "company": { "name": "Stripe, Inc.", "foundedYear": 2010, "emails": ["support@stripe.com"] },
    "classification": { "category": "Business", "subcategory": "Business Software" }
  }
}
```

## Choose an endpoint

| You have | You want | Use | Credits |
|---|---|---|---|
| A company name | Its website | [Resolve](/company-data/resolve) | 1 |
| A card transaction line | The merchant, with its logo | [Card transactions](/company-data/transaction) | 3 |
| A domain | Brand, company and industry in one call | [Enrich](/company-data/enrich) | 12 |
| A domain | Colors, logos and fonts | [Brand](/company-data/brand) | 10 |
| A domain | Legal name, emails and addresses | [Company](/company-data/company) | 5 |
| A domain | Its IAB industry | [Classify](/company-data/classify) | 5 |
| A domain | Its design system, as CSS and Tailwind | [Styleguide](/company-data/styleguide) | 10 |
| A list of domains | Logos to show in your UI | [Logo CDN](/company-data/logo-cdn) | 0 |
| A URL | The page as markdown or JSON | [Scrape](/web-data/scrape) | 1 |
| A URL | A screenshot | [Screenshots](/web-data/screenshot) | 1 |
| A search query | Ranked results, with their text | [Search](/web-data/search) | 2 per 10 |
| A question | A sourced answer in your JSON shape | [Answers](/web-data/answers) | 10 |
| A site | Every URL on it | [Map](/web-data/map) | 1 |
| A site | Every page as markdown | [Crawl](/web-data/crawl) | 1 per page |
| Hundreds of URLs | Scrape, enrich, brand, screenshot and more, as one job | [Batches](/jobs/batches) | Per URL |
| Pages you care about | An alert when they change | [Monitors](/monitors/overview) | 1 per page checked |

See [Credits](/concepts/credits) for the full price list.
