## Credit costs

A credit is one page: fetching, mapping, crawling or screenshotting a page costs 1. Each endpoint consumes a fixed number of credits per successful request:

| Endpoint | Credits | What you get |
|---|---|---|
| `GET /resolve` | 1 | A company or brand name → its domain. 3 when a live lookup runs (`live=true`), 0 when nothing matches |
| `GET /transaction` | 3 | A card transaction line → its merchant. 1 for a line looked up in the last 7 days; +10 with `include_brand` |
| `GET /search` | 2 per 10 results | Web search results, rounded up to the next 10. Each result page scraped: +1 (+4 for `summary` or `json`) |
| `GET /enrich` | 12 | Brand + company + classification |
| `GET /brand` | 10 | Colors, logos, fonts, social links |
| `GET /styleguide` | 10 | Design system: colors by role, type scale, spacing, radii, shadows, components, CSS and Tailwind exports |
| `GET /company` | 5 | Company name, emails, addresses |
| `GET /classify` | 5 | IAB category, descriptions, tickers, ISINs |
| `GET /scrape` | 1 | One page as markdown, HTML, links or images. **+3** when you ask for `summary`, `json` or `check_prompt_injection` |
| `GET /map` | 1 | Every URL a site exposes |
| `POST /crawl` | — | Submitting a crawl is free |
| Each crawled page | 1 per page | Charged as pages complete, never for the `limit` you asked for. 4 per page when `scrape_options` asks for `summary`, `json` or `check_prompt_injection` |
| `DELETE /crawl/{id}` | — | Cancelling a crawl |
| `POST /batch/scrape` | — | Submitting a batch is free |
| Each batch-scraped page | 1 per page | Charged as pages complete, like a crawl. 4 per page when `scrape_options` asks for `summary`, `json` or `check_prompt_injection` |
| `POST /batch/{endpoint}` | — | Submitting a batch of brand, enrich, company, classify, screenshot or styleguide is free |
| Each batch URL answered | the endpoint's price | 12 per URL for `/batch/enrich`, 10 for brand or styleguide, 5 for company or classify, 1 for screenshot |
| Status, errors and cancel calls for crawls and batches | — | Free in themselves |
| `/monitor` calls | — | Creating, reading, changing, running and deleting monitors |
| Each monitor check | 1 per page | Every page the check fetched (4 on targets tracking `json`), plus 1 per changed page judged against your goal |
| `GET /screenshot` | 1 | Webpage screenshot URL, any device, element, format or theme |
| Logo CDN images | — | No credits: each plan includes a monthly quota of logo requests (see [Logo CDN](/api-reference/endpoint/logo-cdn)) |
| `GET /logo/token`, `POST /logo/token/rotate` | — | Your publishable logo token |
| `GET /health` | — | Liveness check |
| `GET /ready` | — | Readiness check |

`summary` and `json` are built by a language model from the page, and `check_prompt_injection` has one read it, which is what the 3-credit surcharge pays for. A page pays it once, however many of the three it asks for. Every other format is the page itself.

## Credits over MCP

The [MCP server](/mcp/overview) charges exactly what the equivalent REST endpoint charges — `prefetch_enrich` costs 12 credits, `prefetch_scrape` costs 1, and so on. There is no surcharge for calling a tool instead of an endpoint.

Several MCP tools are free, because they only manage or read work you have already paid for:

- `prefetch_check_crawl_status` — bills only the crawl or batch pages that completed since your last call.
- `prefetch_cancel_crawl` — never charges.
- `prefetch_logo_urls` — never charges: logos use your plan's logo quota, not credits.
- `prefetch_create_monitor`, `prefetch_list_monitors`, `prefetch_get_monitor`, `prefetch_update_monitor`, `prefetch_delete_monitor` and `prefetch_get_monitor_check` — never charge. A monitor's checks are billed as they run, exactly as over REST; `prefetch_run_monitor` runs one now.

MCP calls also share the request cache with REST calls, so an agent scraping a page you already fetched pays nothing for it.

## When credits are deducted

Credits are deducted **only on successful responses** — meaning the API returned `"success": true` with a `200` status code.

You are **not charged** for:
- Failed requests (4xx or 5xx responses)
- Validation errors (missing URL, bad parameters)
- Authentication failures
- Rate limit rejections (429)
- Timeouts (504)
- Individual crawl pages that failed to fetch (`ok: false`)
- Monitor pages that could not be checked, and monitor checks that were skipped

## How crawls and batches are charged

Submitting a crawl (`POST /crawl`) or a batch (`POST /batch/scrape`, `POST /batch/{endpoint}`) is free. What it returns is billed as it completes:

- **1 credit per page** a crawl or `/batch/scrape` actually returns — **4** when `scrape_options` asks for `summary`, `json` or `check_prompt_injection`.
- **The endpoint's own price per URL** a `/batch/{endpoint}` answers: 12 for enrich, 10 for brand or styleguide, 5 for company or classify, 1 for screenshot.

Pages are charged when you poll the status endpoint, or when the job ends — whichever comes first — and never twice. Three consequences worth knowing:

- You pay for pages **fetched**, never for the `limit` you requested. A crawl capped at 500 pages that finds 12 costs 12 credits, not 500.
- **Polling is free.** Each status call bills only the pages that completed since your previous call, so checking every five seconds costs exactly the same as checking once at the end.
- **Webhooks don't change the price.** A job you only read through its webhooks is charged when it ends, for the pages its webhooks delivered.

Failed pages are never charged. Cancelling charges you for what was fetched before it stopped, and nothing else. A `/batch/{endpoint}` your key cannot pay for in full is refused when you submit it, with a message saying how many URLs fit.

## How searches are charged

A search costs **2 credits per 10 results** returned, rounded up: 10 results cost 2, 11 to 20 cost 4. Result pages you ask to have scraped cost what [`/scrape`](/api-reference/endpoint/scrape) costs, each — and a page that could not be scraped costs nothing.

## How monitors are charged

A [monitor](/api-reference/endpoint/monitor) has no fee of its own — creating, reading, changing and deleting one is free. Each **check** is billed to the API key that created the monitor, when the check finishes:

- **1 credit per page fetched**, the same as `/scrape`, or **4** on targets tracking `json`.
- **1 credit per page judged** against the monitor's goal — only changed, new or removed pages are judged, and only when you set a goal.

A few consequences:

- An hourly check of one page costs 1 credit, about **720 a month**. The `estimated_credits_per_month` on every monitor is an upper bound worked out the same way.
- A check never spends more than your key has left. If credits run out partway, it stops and reports `partial`; if the key has none, the check is recorded as `skipped_no_credits`, costs nothing, and the monitor resumes when your credits refill.
- Pausing a monitor stops its charges without losing its history.

## Plans

Every plan unlocks every endpoint. Plans differ in their monthly credits and how many requests can run at once. Paid plans have no per-minute cap; see [Rate limits](/concepts/rate-limits).

| Plan | Price | Credits per month | Concurrent requests | Requests per minute |
|---|---|---|---|---|
| Free | $0 | 1,000 | 1 | 30 |
| Starter | $11 a month, or $108 a year | 10,000 | 10 | No limit |
| Pro | $49 a month, or $490 a year | 75,000 | 50 | No limit |
| Growth | $149 a month, or $1,490 a year | 300,000 | 150 | No limit |
| Scale | $399 a month, or $3,990 a year | 1,000,000 | 500 | No limit |
| Enterprise | Custom | From 2,000,000 | Custom | No limit |

Plans are listed on the [pricing page](https://prefetch.io/#pricing-section). You can change plan from the [upgrade page](https://prefetch.io/upgrade). An upgrade applies straight away and is charged pro rata; Stripe shows exactly what any change costs before you confirm it.

## Monthly allowance

Every plan's credits refill each month. Unused monthly credits do not roll over.

| Plan | Refills |
|---|---|
| Free | On the day of the month you signed up |
| Paid plans | On each billing date. Annual plans refill on the same day every month |

When your refill day is the 29th, 30th, or 31st, credits refill on the last day of any shorter month.

## Top-ups

There is no overage: when your credits run out, requests stop until they refill. On a paid plan you can buy a top-up pack at any time from the [billing page](https://prefetch.io/billing), and buy several at once:

| Plan | Pack |
|---|---|
| Starter | 2,500 credits for $5 |
| Pro | 10,000 credits for $10 |
| Growth | 35,000 credits for $25 |
| Scale | 100,000 credits for $50 |

Top-up credits are added as soon as the payment completes. They are spent **after** your plan's monthly credits, and they **never expire**: whatever is left carries over every monthly refill, and stays with your account if you change plan.

## Credit limits

Each API key has a `credits_limit`: your plan's monthly allowance plus any top-up credits. When `credits_used` reaches this limit, all further requests return the following until your credits refill or you top up:

```json
{
  "success": false,
  "error": "Credit limit exceeded",
  "meta": { ... }
}
```

Manage and monitor your credit usage from the [dashboard](https://prefetch.io/dashboard).

## Choosing the right endpoint

When you need brand, company, and classification data for a URL, use `/enrich` for a single optimised call instead of three separate requests:

| Scenario | Best approach | Credits spent |
|---|---|---|
| Have a name, need the domain | `/resolve` | 1 (3 with a live lookup) |
| Have a card transaction line, need the merchant | `/transaction` | 3 (1 for a repeat) |
| Need to find pages about something | `/search` | 2 per 10 results |
| Need to show companies' logos | the [logo CDN](/api-reference/endpoint/logo-cdn) | 0 — a monthly quota |
| Need a site's design system for UI work | `/styleguide` | 10 |
| Need 300 domains enriched | `/batch/enrich` | 12 per domain answered |
| Need all three data types | `/enrich` | 12 |
| Need brand + company only | `/enrich` | 12 (15 as `/brand` + `/company`) |
| Need brand only | `/brand` | 10 |
| Need classification only | `/classify` | 5 |
| Need screenshot only | `/screenshot` | 1 |
| Need one page's content | `/scrape` | 1 |
| Need structured JSON from a page | `/scrape` with `formats=json` | 4 |
| Need a site's URL list | `/map` | 1 |
| Need 40 pages of a site | `/crawl` | 40 (1 × 40) |
| Need to know when a page changes | `/monitor`, checking hourly | 1 a check, about 720 a month |
