## Credit costs

Each data extraction endpoint consumes a fixed number of credits per successful request:

| Endpoint | Credits | What you get |
|---|---|---|
| `GET /resolve` | 1 | A company or brand name → its domain. 3 when a live lookup runs (`live=true`), 0 when nothing matches |
| `GET /enrich` | 20 | Brand + company + classification |
| `GET /brand` | 10 | Colors, logos, fonts, social links |
| `GET /company` | 5 | Company name, emails, addresses |
| `GET /classify` | 5 | IAB category, descriptions, tickers, ISINs |
| `GET /scrape` | 3 | One page as markdown, summary, HTML, links, images, or JSON |
| `GET /map` | 3 | Every URL a site exposes |
| `POST /crawl` | 3 | Submitting a crawl |
| `GET /crawl/{id}` | 3 per page | Charged as pages complete, never for the `limit` you asked for |
| `DELETE /crawl/{id}` | — | Cancelling a crawl |
| `/monitor` calls | — | Creating, reading, changing, running and deleting monitors |
| Each monitor check | 3 per page | Every page the check fetched, plus 1 per changed page judged against your goal |
| `GET /screenshot` | 2 | Webpage screenshot URL |
| `GET /health` | — | Liveness check |
| `GET /ready` | — | Readiness check |

## Credits over MCP

The [MCP server](/mcp/overview) charges exactly what the equivalent REST endpoint charges — `prefetch_enrich` costs 20 credits, `prefetch_scrape` costs 3, and so on. There is no surcharge for calling a tool instead of an endpoint.

Several MCP tools are free, because they only manage or read work you have already paid for:

- `prefetch_check_crawl_status` — bills only the crawl pages that completed since your last call.
- `prefetch_cancel_crawl` — never charges.
- `prefetch_create_monitor`, `prefetch_list_monitors`, `prefetch_get_monitor`, `prefetch_update_monitor`, `prefetch_delete_monitor` and `prefetch_get_monitor_check` — never charge. A monitor's checks are billed as they run, exactly as over REST; `prefetch_run_monitor` runs one now.

MCP calls also share the request cache with REST calls, so an agent scraping a page you already fetched pays nothing for it.

## When credits are deducted

Credits are deducted **only on successful responses** — meaning the API returned `"success": true` with a `200` status code.

You are **not charged** for:
- Failed requests (4xx or 5xx responses)
- Validation errors (missing URL, bad parameters)
- Authentication failures
- Rate limit rejections (429)
- Timeouts (504)
- Individual crawl pages that failed to fetch (`ok: false`)
- Monitor pages that could not be checked, and monitor checks that were skipped

## How crawls are charged

A crawl is billed across more than one request:

- **3 credits** when you submit it with `POST /crawl`.
- **3 credits per page** the crawl actually returns, charged on `GET /crawl/{id}` as pages complete.

Two consequences worth knowing:

- You pay for pages **fetched**, never for the `limit` you requested. A crawl capped at 500 pages that finds 12 costs 36 credits, not 1,500.
- **Polling is free.** Each status call bills only the pages that completed since your previous call, so checking every five seconds costs exactly the same as checking once at the end.

Cancelling a crawl charges you for what it fetched before it stopped, and nothing else.

## How monitors are charged

A [monitor](/api-reference/endpoint/monitor) has no fee of its own — creating, reading, changing and deleting one is free. Each **check** is billed to the API key that created the monitor, when the check finishes:

- **3 credits per page fetched**, the same as `/scrape`.
- **1 credit per page judged** against the monitor's goal — only changed, new or removed pages are judged, and only when you set a goal.

A few consequences:

- An hourly check of one page costs 3 credits, about **2,160 a month**. The `estimated_credits_per_month` on every monitor is an upper bound worked out the same way.
- A check never spends more than your key has left. If credits run out partway, it stops and reports `partial`; if the key has none, the check is recorded as `skipped_no_credits`, costs nothing, and the monitor resumes when your credits refill.
- Pausing a monitor stops its charges without losing its history.

## Monthly allowance

Every plan's credits refill each month. Unused credits do not roll over.

| Plan | Credits per month | Refills |
|---|---|---|
| Free | 1,000 | On the day of the month you signed up |
| Standard | 50,000 | On each billing date. Annual plans refill on the same day every month |

When your refill day is the 29th, 30th, or 31st, credits refill on the last day of any shorter month.

## Credit limits

Each API key has a `credits_limit`, which is your plan's monthly allowance. When `credits_used` reaches this limit, all further requests return the following until your credits refill:

```json
{
  "success": false,
  "error": "Credit limit exceeded",
  "meta": { ... }
}
```

Manage and monitor your credit usage from the [dashboard](https://prefetch.io/dashboard).

## Choosing the right endpoint

When you need brand, company, and classification data for a URL, use `/enrich` for a single optimised call instead of three separate requests:

  <Card title="Use /enrich" icon="layer-group">
    20 credits for brand + company + classification.

    Best when you want a complete domain profile in one call.
  </Card>
  <Card title="Use individual endpoints" icon="split">
    More targeted — only pay for what you need.

    Best when you only need one or two data types.
  </Card>
</Columns>

| Scenario | Best approach | Credits spent |
|---|---|---|
| Have a name, need the domain | `/resolve` | 1 (3 with a live lookup) |
| Need all three data types | `/enrich` | 20 |
| Need brand + company only | `/brand` + `/company` | 15 |
| Need brand only | `/brand` | 10 |
| Need classification only | `/classify` | 5 |
| Need screenshot only | `/screenshot` | 2 |
| Need brand + classification | `/brand` + `/classify` | 15 |
| Need one page's content | `/scrape` | 3 |
| Need a site's URL list | `/map` | 3 |
| Need 40 pages of a site | `/crawl` | 123 (3 + 40 × 3) |
| Need to know when a page changes | `/monitor`, checking hourly | 3 a check, about 2,160 a month |
