`/search` runs a web search (Google results) and returns the results best first: each one's `url`, `title` and `description` (the snippet the search engine shows). Set `type=news` for recent articles with their publisher and date.

Ask for page content, and every result page is scraped in the same request, exactly as [`/scrape`](/web-data/scrape) would scrape it, and returned in `scrape` on its result. One call answers "find pages about X and give me their text".

Use `/search` to **find** pages. For a researched answer with sources, use [`/answers`](/web-data/answers). When you already know the page, use `/scrape`.

## Example requests

<CodeGroup>

```bash Results only
curl "https://api.prefetch.io/search?query=open+source+CRM&limit=10" \
  -H "X-API-Key: $PREFETCH_API_KEY"
```

```bash With page content
curl "https://api.prefetch.io/search?query=stripe+pricing&limit=5&formats=markdown" \
  -H "X-API-Key: $PREFETCH_API_KEY"
```

```bash POST, news from the past week
curl -X POST "https://api.prefetch.io/search" \
  -H "X-API-Key: $PREFETCH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "series A funding developer tools",
    "type": "news",
    "time_range": "week",
    "limit": 5,
    "scrape_options": { "formats": ["summary"] }
  }'
```

```javascript Node.js
const res = await fetch("https://api.prefetch.io/search", {
  method: "POST",
  headers: { "X-API-Key": process.env.PREFETCH_API_KEY, "Content-Type": "application/json" },
  body: JSON.stringify({
    query: "headless CMS comparison",
    limit: 5,
    exclude_domains: ["pinterest.com"],
    scrape_options: { formats: ["markdown"], only_main_content: true },
  }),
});
const { data } = await res.json();
for (const r of data.results) {
  console.log(r.position, r.url, r.scrape?.markdown?.content.slice(0, 200) ?? r.scrape_error?.error);
}
```

```python Python
import os, requests

r = requests.post(
    "https://api.prefetch.io/search",
    headers={"X-API-Key": os.environ["PREFETCH_API_KEY"]},
    json={
        "query": "headless CMS comparison",
        "limit": 5,
        "scrape_options": {"formats": ["markdown"]},
    },
)
for result in r.json()["data"]["results"]:
    print(result["position"], result["url"])
```

## Narrowing a search

| Parameter | Does |
|---|---|
| `type` | `web` (default) or `news`. News results carry `source` (the publisher), `date` and `image_url`. |
| `time_range` | `hour`, `day`, `week`, `month` or `year`. |
| `country`, `language` | Two-letter codes, such as `country=de&language=de`. |
| `location` | A city or region to search from, such as `Berlin, Germany`. |
| `include_domains` | Search only these domains (up to 10). |
| `exclude_domains` | Leave these out (up to 10). |

Search operators work in `query` the way they do on Google: `"exact phrase"`, `-word`, `filetype:pdf` and `site:example.com`.

Results on your account's blocklist are dropped, and the rest renumbered.

## Scraping the results

Ask for content with `formats` on `GET` (for example `formats=markdown,links`, plus `only_main_content` and `max_age`), or a `scrape_options` object on `POST` with any option [`/scrape`](/web-data/scrape) takes. Up to **10** results can be scraped in one request.

Result pages are fetched in parallel within one deadline: 45 seconds by default, and `timeout` can shorten it. A page that can't be fetched (blocked, too slow, not a page) gets a `scrape_error` with an [error code](/concepts/errors) instead of `scrape`, and isn't charged. The search itself still succeeds.

## Credits

| What | Credits |
|---|---|
| The search | **2 per 10 results** returned, rounded up, at least 2 |
| Each result page scraped | 1, or 4 with `summary`, `json` or `check_prompt_injection` |
| Result pages that couldn't be scraped | 0 |

A 10-result search costs 2 credits. With every page as markdown, it costs 12.
