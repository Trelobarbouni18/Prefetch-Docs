A monitor checks pages on a schedule and compares each one with the previous check. Instead of polling a pricing page, a changelog or a policy page yourself, you get a webhook or an email with just the change.

<Steps>
  <Step title="Create">
    `POST /monitor` with what to watch, how often, and optionally a goal that describes which changes matter.
  </Step>
  <Step title="Baseline">
    The first check records every page. Nothing is announced, because every page is new.
  </Step>
  <Step title="Check">
    Each scheduled check fetches every page again and marks it `same`, `new`, `changed`, `removed` or `error`, with a diff.
  </Step>
  <Step title="Get told">
    Changes that match your goal are posted to your webhook and emailed to your addresses. You can also read any check with [`GET /monitor/{id}/checks/{checkId}`](/api-reference/endpoint/monitor-check).
  </Step>
</Steps>

## Example request

This monitor watches a competitor's pricing page for price changes and their changelog for new posts, every weekday morning:

<CodeGroup>

```bash cURL
curl -X POST "https://api.prefetch.io/monitor" \
  -H "X-API-Key: $PREFETCH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Competitor pricing",
    "schedule": { "text": "every weekday at 9am", "timezone": "Europe/Athens" },
    "goal": "Alert me when a plan price or its included features change",
    "targets": [
      {
        "type": "scrape",
        "urls": ["https://example.com/pricing"],
        "change_tracking": { "modes": ["json"], "json_prompt": "Each plan: name, monthly price, headline features" }
      },
      {
        "type": "crawl",
        "url": "https://example.com/changelog",
        "crawl_options": { "limit": 25, "include_paths": ["^/changelog/"] }
      }
    ],
    "webhook": { "url": "https://you.example.org/hooks/prefetch" },
    "email": { "to": ["you@example.com"] }
  }'
```

```python Python

    "https://api.prefetch.io/monitor",
    headers={"X-API-Key": os.environ["PREFETCH_API_KEY"]},
    json={
        "name": "Competitor pricing",
        "schedule": {"text": "every weekday at 9am", "timezone": "Europe/Athens"},

        "targets": [
            {
                "type": "scrape",
                "urls": ["https://example.com/pricing"],
                "change_tracking": {"modes": ["json"], "json_prompt": "Each plan: name, monthly price, headline features"},
            },
            {
                "type": "crawl",
                "url": "https://example.com/changelog",
                "crawl_options": {"limit": 25, "include_paths": ["^/changelog/"]},
            },
        ],
        "webhook": {"url": "https://you.example.org/hooks/prefetch"},
        "email": {"to": ["you@example.com"]},
    },
)
monitor = r.json()["data"]
print(monitor["id"], monitor["webhook"]["secret"])
```

## Credits

Creating, reading and changing a monitor is free. **Each check** costs 1 credit per page fetched, plus extra for `json` extraction, search targets and judging. See [Limits and credits](/monitors/limits).

<Warning>
A monitor bills on every check for as long as it's active. A crawl target with `limit: 100` on a 5-minute schedule fetches 28,800 pages a day. Start small, and pause monitors you aren't using.
</Warning>

<Note>
Monitors need a direct Prefetch API key. They aren't available through RapidAPI, which bills from a response header, and a scheduled check runs when there's no response to carry one.
</Note>
