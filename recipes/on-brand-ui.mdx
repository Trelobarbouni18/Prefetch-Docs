Building a demo, a landing page or an email template that should look like a customer's brand? [`/styleguide`](/company-data/styleguide) reads the site's real colors, type scale, spacing, radii, shadows and button styles, and hands them back as a Tailwind theme and CSS custom properties.

**Cost:** 10 credits per site.

## 1. Fetch the styleguide and save the exports

<CodeGroup>

```javascript Node.js
import { writeFile } from "node:fs/promises";

const site = process.argv[2] ?? "https://linear.app";
const res = await fetch(`https://api.prefetch.io/styleguide?url=${encodeURIComponent(site)}`, {
  headers: { "X-API-Key": process.env.PREFETCH_API_KEY },
});
const { success, data, error } = await res.json();
if (!success) throw new Error(error);

await writeFile("brand.css", data.exports.css);
await writeFile("tailwind.brand.js", `export default ${JSON.stringify(data.exports.tailwind, null, 2)};\n`);
await writeFile("styleguide.json", JSON.stringify(data.styleguide, null, 2));
```

```python Python
import json, os, sys, requests

site = sys.argv[1] if len(sys.argv) > 1 else "https://linear.app"
body = requests.get(
    "https://api.prefetch.io/styleguide",
    params={"url": site},
    headers={"X-API-Key": os.environ["PREFETCH_API_KEY"]},
    timeout=60,
).json()
if not body["success"]:
    raise SystemExit(body["error"])

data = body["data"]
open("brand.css", "w").write(data["exports"]["css"])
json.dump(data["exports"]["tailwind"], open("tailwind.brand.json", "w"), indent=2)
json.dump(data["styleguide"], open("styleguide.json", "w"), indent=2)
```

</CodeGroup>

## 2. Use the theme

Add the preset to your Tailwind config:

```javascript tailwind.config.js
import brand from "./tailwind.brand.js";

export default {
  presets: [brand],
  content: ["./src/**/*.{js,ts,jsx,tsx}"],
};
```

Or import `brand.css` and use the variables directly, like `var(--color-primary)`.

## 3. Check what you got

The styleguide is best effort: a value the page gives no reliable answer for is `null`. Before you build, check `colors.primary`, the `h1` and `body` styles, and `components.button_primary`. Fill gaps by hand, or from [`/brand`](/company-data/brand), which also returns logos.

Sites with a dark theme can be read with `dark_mode=true`. `color_scheme` tells you which theme you got.
