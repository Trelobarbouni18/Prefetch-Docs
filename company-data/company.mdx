`/company` finds the organization behind a website. It reads structured data (JSON-LD, schema.org), the footer, contact pages and other signals, and returns them under `data.company`:

- **Names:** the legal entity (`Stripe, Inc.`) and the name people use (`Stripe`)
- **Emails:** contact and support addresses
- **Addresses:** street, city, state, postal code and country, plus the address as written
- **Facts:** employee count, founding year and parent company, when known
- **Key pages:** the `about`, `pricing`, `careers`, `contact`, `blog` and `docs` pages the homepage links to

Static pages are read with a fast fetch. A real browser is used only when the page needs JavaScript.

## Example requests

<CodeGroup>

```bash cURL
curl "https://api.prefetch.io/company?url=https://stripe.com" \
  -H "X-API-Key: $PREFETCH_API_KEY"
```

```javascript Node.js
const res = await fetch("https://api.prefetch.io/company?url=https://stripe.com", {
  headers: { "X-API-Key": process.env.PREFETCH_API_KEY },
});
const { data } = await res.json();

console.log(data.company.name);              // "Stripe, Inc."
console.log(data.company.emails);            // ["support@stripe.com"]
console.log(data.company.addresses[0].city); // "South San Francisco"
```

```python Python
import os, requests

r = requests.get(
    "https://api.prefetch.io/company",
    params={"url": "https://stripe.com"},
    headers={"X-API-Key": os.environ["PREFETCH_API_KEY"]},
)
company = r.json()["data"]["company"]
print(company["name"])
print(company["addresses"][0]["raw"])
```

## Fields

| Field | Meaning |
|---|---|
| `name` | The legal or trading name. |
| `display_name` | The short name people use. |
| `parentCompany`, `employeeCount`, `foundedYear` | Company facts, or `null` when unknown. |
| `isNsfw` | Whether the site's content is not safe for work. |
| `emails` | Contact and support addresses found on the site. |
| `addresses` | Each address as written (`raw`) and split into `street`, `city`, `state`, `postal_code` and `country`. Any part can be `null`, and the list is often empty. Handle an address that arrives as a plain string too. |
| `social_links` | Profile URLs keyed by platform, when found. `/enrich` puts them here too. |
| `links` | The site's `about`, `pricing`, `careers`, `contact`, `blog` and `docs` pages, each `null` when the homepage links none. |

Well-known companies are answered from curated data in milliseconds, and curated answers can leave out `links` and `social_links`. Other sites are read live. Treat every field as optional.
