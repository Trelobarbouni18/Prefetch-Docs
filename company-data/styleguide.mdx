`/styleguide` renders a page in a real browser and reads its design system off what's on screen, the way a designer would write it down to rebuild the site's look:

- **Colors by role:** `primary` (the main button's fill), `secondary`, `accent`, `background`, `surface`, `text`, `text_muted`, `heading`, `link` and `border`, plus the full palette.
- **Typography:** the heading, body and monospace faces with their font stacks, and the type scale: `h1` to `h6`, `body`, `small`, `label` and `nav`, each with size, weight, line height, letter spacing and text transform. The ratio between steps is reported, and named when it's a classic one (*major third*, *perfect fourth*).
- **Spacing:** the base unit most margins and paddings are a multiple of, and the scale in use.
- **Radii and shadows:** small, medium and large, and whether the site uses pills.
- **Components:** the primary and secondary button (fill, text, border, radius, weight, font size, height, padding, shadow), the input, the card and the link.
- **Breakpoints:** the widths where the CSS changes layout.
- **CSS variables:** the site's own custom properties for colors, lengths, fonts and shadows.

`exports` has the same guide as **CSS custom properties** and a **Tailwind theme**, ready to paste. Point a coding agent at a site and it can build UI that looks like it.

For logos, the logo's own colors, fonts and social links, use [`/brand`](/company-data/brand).

## Example requests

<CodeGroup>

```bash cURL
curl "https://api.prefetch.io/styleguide?url=https://stripe.com" \
  -H "X-API-Key: $PREFETCH_API_KEY"
```

```bash Dark theme
curl "https://api.prefetch.io/styleguide?url=https://github.com&dark_mode=true" \
  -H "X-API-Key: $PREFETCH_API_KEY"
```

```javascript Node.js (write a Tailwind preset)
import { writeFile } from "node:fs/promises";

const res = await fetch("https://api.prefetch.io/styleguide?url=https://linear.app", {
  headers: { "X-API-Key": process.env.PREFETCH_API_KEY },
});
const { data } = await res.json();

await writeFile("brand.css", data.exports.css);
await writeFile("tailwind.brand.js", `export default ${JSON.stringify(data.exports.tailwind, null, 2)};\n`);
```

```python Python
import json, os, requests

r = requests.get(
    "https://api.prefetch.io/styleguide",
    params={"url": "https://linear.app"},
    headers={"X-API-Key": os.environ["PREFETCH_API_KEY"]},
)
data = r.json()["data"]

with open("brand.css", "w") as f:
    f.write(data["exports"]["css"])
with open("tailwind.brand.json", "w") as f:
    json.dump(data["exports"]["tailwind"], f, indent=2)
```

## How it reads a site

Everything comes from computed styles in the rendered page, so it reflects what visitors see, whatever CSS framework the site uses:

- Colors are read in any CSS color space (`oklch()`, `lab()` and `color()` included) and returned as hex. Translucent colors are blended over what's behind them.
- A text style is the one most instances of an element share, weighted by text, so one oversized hero heading doesn't speak for every heading.
- Spacing, radii and shadows are counted across up to 2,500 visible elements. One-off values don't make the scale, Tailwind's transparent placeholder shadows are dropped, and hairline "ring" shadows count as borders, not elevation.
- `css_variables` lists the custom properties in scope on the page, with names that look like design tokens first.

It's best effort: a value the page gives no reliable answer for is `null`. Set `dark_mode=true` to read a site's dark theme, and `color_scheme` tells you which theme you got.
