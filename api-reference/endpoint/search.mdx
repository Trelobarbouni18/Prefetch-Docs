description: "Search the web and get each result's title, URL and snippet, optionally with every result page scraped. 2 credits per 10 results."
openapi: "GET /search"
---

Runs a web search and returns ranked results, optionally scraping each result page in the same call. `POST /search` takes the same fields as a JSON body, with `scrape_options`.

**2 credits per 10 results**, plus what each scraped page costs. Failed requests are never charged.
