title: "POST /batch/{endpoint}"
sidebarTitle: "Start a batch"
description: "Run brand, enrich, company, classify, screenshot or styleguide on up to 500 URLs as one job. Free to submit."
openapi: "POST /batch/{endpoint}"
---

Starts a batch of one endpoint and returns `202` with a job id. Read results with [`GET /batch/{endpoint}/{id}`](/api-reference/endpoint/batch-status).

**Free to submit.** Each URL answered costs what one call of that endpoint costs. Failed requests are never charged.
