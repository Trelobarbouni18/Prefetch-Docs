Fetches one URL and returns it in the formats you ask for. `POST /scrape` takes the same options as a JSON body, which is easier for `json_schema` and `headers`.

**1 credit**, +3 for `summary`, `json` or `check_prompt_injection`. Failed requests are never charged.
