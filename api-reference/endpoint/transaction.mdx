---
title: "GET /transaction"
sidebarTitle: "Card transaction"
description: "Turn a card transaction descriptor into its merchant: name, website, logo, processor and location. 3 credits, 1 for a repeat."
openapi: "GET /transaction"
---

Reads a bank statement line and returns the merchant behind it, or says it's a person, transfer, fee, ATM withdrawal or refund. `POST /transaction` takes the same fields as a JSON body.

**3 credits**, 1 for a line looked up in the last 7 days, +10 with `include_brand`. Failed requests are never charged.
