## Overview

Returns your monitors with their settings, next run, credit estimate and the summary of each one's last check. Results are paginated: follow `next` until it is `null`.

An API key sees only the monitors it created.

## Example request

<CodeGroup>

```bash cURL
curl "https://api.prefetch.io/monitor?limit=25" \
  -H "X-API-Key: $PREFETCH_API_KEY"
```

```javascript Node.js
const res = await fetch("https://api.prefetch.io/monitor", {
  headers: { "X-API-Key": process.env.PREFETCH_API_KEY },
});
const { data } = await res.json();

for (const m of data.monitors) {
  const last = m.last_check_summary;
  console.log(m.name, m.status, last ? `${last.changed} changed` : "no check yet");
}
```

```python Python
import os, requests

data = requests.get(
    "https://api.prefetch.io/monitor",
    headers={"X-API-Key": os.environ["PREFETCH_API_KEY"]},
).json()["data"]

for m in data["monitors"]:
    print(m["name"], m["status"], m["next_run_at"])
```

</CodeGroup>
