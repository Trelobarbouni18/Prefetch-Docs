## Overview

The same response as [`GET /crawl/{id}`](/api-reference/endpoint/crawl-status), with `kind: "batch"`: progress, plus a page of scraped pages in completion order. Follow `next` until it is `null` to read every page. Results stay readable for **24 hours** after the batch finishes.

Each page carries `ok`. A failed page has `ok: false`, an `error`, and an [`error_code`](/concepts/errors#error-codes), and is not charged.

## Example request

```bash cURL
curl "https://api.prefetch.io/batch/scrape/crw_5a8d2e7f1c4b4a9e8d3c6b1a0f9e8d7c" \
  -H "X-API-Key: $PREFETCH_API_KEY"
```
