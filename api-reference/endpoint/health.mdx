---
title: "GET /health"
sidebarTitle: "Health"
description: "Check that the Prefetch API is up. No API key needed, and free."
openapi: "GET /health"
---

Returns `200` with `{"status": "ok"}` while the API is running. It needs no API key and costs nothing, so you can point your own uptime monitoring at it.

```bash
curl https://api.prefetch.io/health
```

```json
{ "status": "ok" }
```

For incidents and uptime history, see the [status page](https://prefetch.betteruptime.com/). For a check that also confirms Prefetch can accept background jobs, use [`GET /ready`](/api-reference/endpoint/ready).
