---
title: "GET /ready"
sidebarTitle: "Readiness"
description: "Check that the Prefetch API can accept requests and background jobs. No API key needed, and free."
openapi: "GET /ready"
---

Returns `200` when the API is ready to handle requests, including the queue that runs crawls, batches and monitor checks. It returns `503` when that queue is unavailable. It needs no API key and costs nothing.

```bash
curl https://api.prefetch.io/ready
```

```json 200 Ready
{ "status": "ok" }
```

```json 503 Not ready
{ "status": "error", "message": "Redis connection failed" }
```

To check only that the API is running, use [`GET /health`](/api-reference/endpoint/health).
