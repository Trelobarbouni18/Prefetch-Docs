## Base URL

```
https://api.prefetch.io
```

## Authentication

All endpoints (except `/health` and `/ready`) require an `X-API-Key` header.

```bash
curl https://api.prefetch.io/classify?url=https://example.com \
  -H "X-API-Key: your_api_key"
```

See [Authentication](/concepts/authentication) for full details including first-party origin injection.

## Response format

Every response uses a consistent envelope:

```json
{
  "success": true,
  "data": { },
  "meta": {
    "requestId": "uuid-v4",
    "durationMs": 1234
  }
}
```

On error, `success` is `false` and `data` is replaced by `error`:

```json
{
  "success": false,
  "error": "Credit limit exceeded",
  "meta": {
    "requestId": "uuid-v4",
    "durationMs": 8
  }
}
```

## Credit costs

| Endpoint | Credits |
|---|---|
| `GET /enrich` | 12 |
| `GET /brand` | 10 |
| `GET /company` | 5 |
| `GET /classify` | 5 |
| `GET /scrape` | 1 (+3 for `summary` or `json`) |
| `GET /map` | 1 |
| `POST /crawl` | Free to submit, 1 per page returned (4 with `summary` or `json`) |
| `GET /crawl/{id}` | Charged per page as pages complete |
| `DELETE /crawl/{id}` | — |
| `POST /monitor` and the other monitor calls | — |
| Each monitor check | 1 per page fetched (4 in `json` mode), plus 1 per change judged |
| `GET /screenshot` | 1 |
| `GET /health` | — |
| `GET /ready` | — |

Credits are deducted only on successful responses. Every plan's allowance refills monthly, including the Free plan's 1,000 credits. See [Credits](/concepts/credits).

## Asynchronous endpoints

Every endpoint answers in one round trip except `/crawl`. A crawl runs for minutes, so `POST /crawl` returns `202` with a job id and you poll `GET /crawl/{id}` for results. See [POST /crawl](/api-reference/endpoint/crawl).

Monitors run on their own schedule. `POST /monitor` sets one up, and each check's results arrive at your webhook or are read with `GET /monitor/{id}/checks/{checkId}`. See [POST /monitor](/api-reference/endpoint/monitor).

## Rate limits

- **Global:** 300 requests per minute per IP
- **Per key:** Configurable sliding window (1-minute) set on your API key

Exceeding either limit returns HTTP 429. See [Rate limits](/concepts/rate-limits).
