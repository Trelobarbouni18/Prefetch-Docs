## Base URL

```
https://api.prefetch.io
```

## Authentication

Every endpoint except `/health` and `/ready` needs an `X-API-Key` header:

```bash
curl "https://api.prefetch.io/classify?url=https://example.com" \
  -H "X-API-Key: $PREFETCH_API_KEY"
```

See [Authentication](/concepts/authentication) for OAuth, bearer tokens and key errors.

## Response envelope

Every response has the same shape:

```json
{
  "success": true,
  "data": { },
  "meta": {
    "requestId": "uuid-v4",
    "durationMs": 1234
  }
}
```

On failure, `success` is `false` and `data` is replaced by an error:

## Conventions

- **Parameters** are snake_case (`only_main_content`), except on `/brand` and `/enrich`, which take camelCase (`screenshotColors`). Batches and MCP take snake_case everywhere.
- **GET or POST:** `/scrape`, `/search` and `/transaction` accept the same fields as a query string on `GET` or a JSON body on `POST`. Use `POST` for nested options like `json_schema`, `headers` or `scrape_options`.
- **URLs** can omit the scheme. `stripe.com` means `https://stripe.com`.
- **Request bodies** can be up to 1 MB.
- **Time limits:** most requests finish within 55 seconds, or fail with `TIMEOUT`. Give your HTTP client at least 60.
- **Ids** carry a prefix: `crw_` for crawls and batches, `mon_` for monitors, `chk_` for monitor checks.

## Background jobs

Crawls, batches and monitor checks run in the background. `POST /crawl`, `POST /batch/scrape`, `POST /batch/{endpoint}` and `POST /monitor/{id}/run` return `202` with an id, and you read the results with the matching `GET`, or get them by [webhook](/concepts/webhooks). See [Async jobs](/concepts/async-jobs).

## Rate limits

Each plan limits how many requests can run at once, from 1 on Free to 500 on Scale. The Free plan also allows 30 requests a minute. Going over either returns `429`. See [Rate limits](/concepts/rate-limits).
